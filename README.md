# GSB Bugfix Task
## 题面
组队语音房间上线后，队伍里经常出现两个麦位同时说话，踢掉的人换个设备又回来了。同一账号两个设备加入，房间出现两个麦位；被踢出后重连又回到房间；房主掉线后房主转给一个已经离线的玩家；自己静音后队友还能听到，队友静音后自己这边却还能听到对方；跨服队伍语音房间编号冲突，进到了另一支队伍；断线重连后麦克风状态错误，一直占着麦；房间人数上限并发加入，最后多进两个人；切到另一个频道后旧频道还能说话；屏蔽玩家后仍能听到对方声音；房间解散后语音资源没释放，房间越积越多；语音延迟和队伍标记不同步，指挥喊了才动；队伍解散后语音房间还挂着，新队伍能直接进到旧房间的麦位。voice_room_arbiter.py 的 VoiceRoomArbiter 负责 join、leave、mute、transfer、kick 和 close，成员、麦位和频道状态各存一份。希望账号在房间内唯一，踢出写黑名单，房主只转给在线成员，静音状态以服务端为准，房间编号全局唯一，重连恢复原麦位，人数上限原子校验，频道切换先退订旧频道，屏蔽在混音前过滤，解散释放全部资源，语音状态和队伍标记同源。test_voice_room_arbiter.py 的十五条检查现在没有一条通过，压双设备、踢出重连、房主离线、静音、跨服房间号、重连麦位、人数、频道、屏蔽、解散、状态同步和唯一性。

## 运行方式
```bash
python -m pytest tests -q
```
