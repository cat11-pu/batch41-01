# GSB Bugfix Task
## 题面
赛季结算把竞技场、战场和副本竞速三套积分直接相加以后，段位名单彻底没法看。三套分的量纲差了一个数量级，战场分把竞技场分完全淹没；每个玩法的积分上限写在求和之后，总分还是能超上限；参与场次不够的玩家按零分参与排名，把正常玩家挤下去；同一场对局被两个统计任务各记一次，积分凭空翻倍；对局归属按结算时间而不是开始时间，跨零点那批算进了新赛季；衰减只对竞技场生效，战场分一分不掉；跨服积分没有汇总，合服后名单少了一半人；百分位段位用整数除法切档，边界上的玩家整批跳档；并列分数按角色名排序，改个名字名次就变；增量重算和全量重算结果对不上，运营不知道信哪份；被封禁的玩家还在参与段位线计算，正常玩家被压下去；赛季切换时三个玩法不是同一时刻冻结，先结算的玩法分数被新赛季覆盖。season_score_normalizer.py 的 SeasonScoreNormalizer 里 aggregate、normalize、cutoff、recompute 和 snapshot 各算一套分数。希望先把各玩法归一到统一量表，再按权重和上限汇总；参与门槛单独判断；对局结果按开始时间归属；衰减规则统一；跨服按全局角色汇总；百分位边界按明确规则取整；同分用稳定键排序；增量与全量共用同一实现；封禁玩家不参与段位线；重置时清空当期积分并留归档。test_season_score_normalizer.py 的十五个用例现在全部失败，压量纲、上限位置、参与门槛、重复计入、赛季归属、衰减、跨服、百分位、并列、增量一致、封禁和同时冻结。

```bash
python -m pytest tests -q
```
