# GSB Bugfix Task
## 题面
主机入侵检测靠进程树判断异常行为，上周一台机器被挖矿，告警一条都没出。父进程退出后 ppid 被系统复用，血缘接到了完全无关的进程上；容器里的进程血缘越过命名空间边界，和宿主机进程混在一起；白名单按进程名匹配，所有 java 进程一律被当成可信；大量短命进程在两次采样之间创建又退出，完全漏检；进程可执行文件被删除后 /proc 下读不到，血缘直接断链；攻击者用 setsid 脱离会话，进程树断成两截；事件乱序到达，子进程的记录先于父进程；进程名里带空格和括号，解析时被截断；白名单按命令行前缀匹配，加一个参数就绕过去；血缘深度没有上限，构造一条超长链把检测拖垮。process_lineage_gate.py 的 ProcessLineageGate 要以 pid 加启动时间作为进程键，容忍乱序事件并缓存短命进程，检测 ppid 复用，按命名空间隔离血缘，exe 缺失时降级到可执行文件哈希，白名单要求精确匹配，设血缘深度上限，输出完整链路和判定依据。test_process_lineage_gate.py 的十五个用例现在全部报错，分别压 ppid 复用、跨命名空间、同名进程、短命进程、exe 缺失、setsid、乱序事件、名称解析、白名单前缀、深度上限、空事件、重复事件、父子倒挂、缓存过期和结果隔离。

## 运行方式
```bash
python -m pytest tests -q
```
