# GSB Bugfix Task
## 题面
史莱姆首领死亡溶解的效果上线后，美术在近景截图里发现黏液表面全是裂缝，块与块之间漏出背景；同一团胶体换成小半径后，高光位置发黑，像法线反了；阈值调到边界值时，整团直接消失，再调回来又变成实心球；负半径的调试参数没有拦住，网格里出现 NaN 顶点，包围盒算成无穷大；自适应细分在大小球交界处深度差了两级，边上出现 T 型接缝；同一格在一帧里被两个特效重复提交，顶点数翻倍、内存一直涨；顶点预算超了就按三角形序号硬截断，模型下半截直接没了；场值正好等于等值面的点归属不稳定，两次生成的结果不一样；多线程并行网格化时共享的顶点缓存没有加锁，接缝处出现重复顶点和脏法线；索引偶尔为负，渲染器整批丢弃。metaball_march.py 的 MetaballMarch 现在把场计算和网格化写成一坨，要拆出 field、polygonize 和 stats：相邻格子必须复用同一条边上的顶点，场值比较留对称容差，负半径和非有限值直接拒绝，自适应深度受单帧八毫秒预算约束且邻居最多差一级，法线按中心差分并归一化，输出顶点、索引、法线和本次统计。把这十五条用例跑一遍，目前没有一条能立住。

## 运行方式
```bash
python -m pytest tests -q
```
