# GSB Bugfix Task
## 题面
舞台演出场景换成实时渲染后，聚光灯下人物的影子边缘出现一圈圈条纹，走近墙面时影子又硬得像刀切；灯的面积调大，半影范围却不变，远看近看都一样硬；地面出现大片痤疮状黑点，加大深度偏移后影子又和脚底分离；阴影贴图图集边界没留余量，相邻灯的光斑串到画面边缘；穿纱裙的舞者被当成完全不透明遮挡，裙摆投出一整块硬影；每帧随机抖动的噪点没有做时域累积，静止镜头也在闪；两盏灯并行更新同一格图集时互相覆盖，切换灯位后影子跟着换主人；阴影图分辨率从 2K 降到 1K，半影世界尺寸没跟着换算，软硬程度跳变；光源半径填 0 时计算里出现除零，整块画面变黑；1080p 下每像素遮挡搜索没有上限，帧时间从 16ms 涨到 30ms。pcss_penumbra_filter.py 的 PcssPenumbraFilter 里，遮挡体搜索和半影估计是两件事，必须分开做：半影大小由光源世界尺寸、遮挡距离和阴影图 texel 世界尺寸共同决定，图集采样加保护带，半透明按不透明度计入遮挡权重，抖动序列固定并可复现，半径为 0 退化成硬阴影，分辨率变化保持世界空间半影一致，同时输出可见度、半影尺寸和采样计数。现有十五条用例逐一跑下来，全部是红的。

## 运行方式
```bash
python -m pytest tests -q
```
