# GSB Bugfix Task
## 题面
新会长上任第一晚就在管理后台把自己锁在了门外，随后把能试的操作全试了一遍，问题一条条浮出来。自定义角色挂在副会长下面，副会长职位被删掉后，这批成员的权限整片变空；权限缓存十分钟才失效，被踢的人照样能打开仓库；同一个账号在一区是官员，切到二区显示普通成员；两个管理同时任命，职位人数上限被双双突破；踢人之后仓库借用锁没有归还，新成员进不了门；副会长能给自己加权限，也能给同级的另一个角色加；权限检查只看职位不看频道，普通成员发出了公会通知；公会已经解散，审批单还能处理，物品发进了一个不存在的公会；成员改名后审计日志按旧名字搜不到人；成员操作和权限调整撞在一起，检查刚通过权限就被撤走；会长把位置转给小号，冷却时间没有生效；公告撤掉发布权限后编辑按钮还亮着，点进去居然还能改。guild_scope_matrix.py 的 ScopeMatrix 里，授权、检查、回收、入会和解散各查一份缓存。希望角色继承用快照或引用计数，缓存按版本失效，跨区身份同步，人数上限原子校验，锁随成员释放，授予权限不能自授且需要上级，频道范围参与校验，解散后队列作废，审计用角色编号，权限检查与操作同事务或带版本，转让设冷却。test_guild_scope_matrix.py 的十五项检查铺开一看，全是红的。
