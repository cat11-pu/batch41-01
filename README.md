# GSB Bugfix Task
## 题面
活动积分里程碑上线后，运营发现有人第一天就把全服进度刷满了。同一个任务重复交，积分加两次；里程碑奖励可以跳着领，领了第五档却没领第三档；活动结束之后还能继续刷积分；积分上限只校验单次获得，累加后还是能超；跨服玩家积分记在源服，目标服的里程碑一直不亮；全服里程碑进度被个人进度覆盖，个人刷分全服跟着涨；补发邮件按当前积分算，活动期间已经达标的玩家反而没补；里程碑奖励领取没有幂等，连点两次领两份；活动配置热更后，已达标玩家被降档；积分排行榜和里程碑用的不是同一份积分；活动切换时积分没清，下一期开局直接满档。event_milestone_track.py 的 MilestoneTrack 负责 award、claim、progress、compensate 和 rotate，个人积分、全服积分和领奖记录各存一份。希望任务奖励按任务编号幂等，里程碑按顺序领取，活动窗口外拒绝积分，累计上限在写入时校验，跨服积分汇总到全局角色，个人和全服分两条账，补发按历史快照，领取带幂等键，热更带版本号，排行榜和里程碑共用一份积分，活动切换清空当期并归档。test_event_milestone_track.py 的十五个用例眼下全部失败，压重复交任务、跳档领取、活动结束、累计上限、跨服、全服覆盖、补发、重复领取、热更降档、积分源、切换清零、幂等和窗口。

## 运行方式
```bash
python -m pytest tests -q
```
