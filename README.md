# GSB Bugfix Task
## 题面
运营把一段重铸直播的录屏逐帧截出来发给我们，锁住的词条在结果里换了内容，弹幕当场就炸了。玩家勾选了三条例外词条，重铸完成三条全变；同一次重铸里冒出两行完全相同的属性，面板只显示一行；三十级的护腕洗出了只有满级池才有的词条；确认框里展示的数值和最终写入的差一档，两边读的不是同一份候选池；材料已经扣走，装备却停在半成品状态，词条栏空着；连续洗了五次，历史里只留下最后一次，前四次的结果查不到；套装效果在重铸后失效，要脱下来再穿上才恢复；隔壁区服的界面还挂着旧属性，得重新登录才刷新；点反悔以后材料不退，只回滚了词条；两个请求同时打进来，后完成的那次把先完成的覆盖；低品质装备疯狂出高级词条，权重表看着像是按品质反着配的；预览弹窗关掉再点确认，材料已经被扣过一次。affix_reforge.py 的 AffixReforge 里，负责预览、重铸、锁定、反悔和历史的几个入口分别持有词条池、锁定状态与历史记录。希望被锁的词条不进入候选池，词条按编号唯一，等级受装备等级约束，预览与结算共用同一随机序列，材料与词条同事务提交，历史逐次保留，套装效果重算，两区比对时带版本，反悔按历史记录返还，每件底子各自加锁，权重按品质分开配置。test_affix_reforge.py 我没跑通，每条都停在同一个断言上。
