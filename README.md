# GSB Bugfix Task
## 题面
手游多 pass 渲染一开内存别名，低端机不再被杀进程，但画面开始出现上一帧的残影；两个生命周期重叠的渲染目标被分到同一块内存，后写的把前一个盖掉；分配只看字节大小，没管格式、采样数和移动端 tile 限制，创建直接失败；别名屏障插在错误的 pass 之间，采样时上一 pass 还没写完；瞬态目标在帧间复用，GPU 还在飞行中就覆盖；多个线程并行录制命令，分配器没有锁，两个 pass 拿到同一块内存；分辨率切换后别名计划没重算，写越界；一个 pass 先写后读同一资源，却被判成可别名，画面花掉；UI 和视频这类外部纹理被纳进别名池，生命周期外被清空；内存刚好卡在预算线上，分配来回抖，帧率忽高忽低；零尺寸和超大尺寸目标没有拒绝；计划编译 2ms，超出预算。rt_alias_plan.py 的 RtAliasPlan 要按资源的生命周期区间分配内存，兼容性检查覆盖格式、采样数和 tile 约束，读写同一个资源的 pass 不能重叠，屏障插在真实依赖之间，飞行中的资源有在途保护，并发分配串行化或加锁，分辨率变化整体重算，外部资源排除在池外，边界尺寸拒绝，预算内做图着色或贪心分配，输出分配表、复用次数和峰值内存。这十五条用例目前没有一条跑得通。
