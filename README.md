# GSB Bugfix Task
## 题面
交易行从单服改成跨服镜像后，同一件装备在两个服都能看到可购买，买家拍下后两边都扣了钱。挂单在源服创建，镜像到目标服有延迟，等待期间两边价格不一样；同一张挂单在两个镜像都被买走，物品直接双花；撤单只在源服生效，目标服列表还能点购买；跨服购买成功后物品入到错误的服务器背包；镜像重放旧消息，已经成交的挂单又复活；两个服网络分区时各自成交，恢复后冲突没法合并；税率按买家所在服算，和源服结算金额对不上；托管库存和镜像展示数量越差越多；镜像追赶时用全量覆盖，把增量里的新挂单冲掉；源服下架后目标服缓存还没过期，玩家买到空气；跨服搜索把同一张挂单返回两次。market_mirror_ledger.py 的 MarketMirrorLedger 负责 publish、replicate、purchase、cancel 和 reconcile，镜像缓存和源服托管各写一份。希望每张挂单只有一个写入方，所有变更带递增版本，购买在源服加锁并校验版本，撤单写墓碑同步到所有镜像，物品按源服归属路由，事件按幂等键消费，分区恢复按版本对账，税率在结算服统一计算，托管账本单一来源，增量同步带水位，缓存按版本失效，搜索按挂单编号去重。test_market_mirror_ledger.py 的十五个用例眼下全红，压镜像延迟、双买、撤单失效、入包错服、旧消息复活、分区冲突、税率、库存差、全量覆盖、缓存过期、搜索重复、版本和幂等。

## 运行方式
```bash
python -m pytest tests -q
```
