# GSB Bugfix Task
## 题面
这周的卡牌消耗对账和玩家工单对上了同一条线：升星吃掉的同名卡和星级变化根本不成比例。有人把同一张材料卡拖进两个升星槽，结算时这张卡被算了两遍；升完星卡牌的等级回到一级，之前喂进去的经验药水等于白喂；星级已经封顶的卡还能继续投材料，点了确认材料直接没影；稀有度和同名规则没分开，紫卡的位置被一张白卡占掉；面板上写的是攻击加百分之八，升完只加了五，预览和结算各读一份表；两个线程同时处理同一张卡，材料扣两次星级只动一格；升星后原本上锁的卡变成未锁，被批量分解脚本扫走；分解返还按当前星级折算，玩家投入的高星材料拿不回来；升星相关的任务计数被重复记，同一个任务奖励领了两回；转服之后目标服还显示旧的星级，卡组战力对不上；反悔操作只把星级退回去，技能点没有跟着还；材料卡还挂在卡组里，升星时被直接吞掉，进副本才发现卡组少一张，只能临时拼。card_star_up.py 里 CardStarUp 的 preview、star_up、consume、decompose、revert 各自维护材料、星级和技能点三份状态。希望材料按唯一实例消费，升星保留等级并重算技能，到顶直接拒绝，同名与品质规则写死，预览和结算共用一个随机源，单卡加锁，锁定状态继承，分解按实际投入折算，任务计数幂等，转服同步带版本号，反悔时技能点一并归还。test_card_star_up.py 的用例连跑三轮，没有一轮能跑完。

## 运行方式
```bash
python -m pytest tests -q
```
