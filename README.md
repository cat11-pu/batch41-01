# GSB Bugfix Task
## 题面
多语言版本上线后，阿拉伯语和中文混排的界面开始出问题：大字号标题边缘发糊，小字号又缺笔画；SDF 扩散范围按固定值生成，字号放大后精度不够；图集满了直接覆盖正在显示的字形，聊天框里文字变成方块；字体回退链只配了主字体，中日韩和 emoji 全显示豆腐块；字距调整只查主字体，回退字形挤在一起；阿拉伯语没有做双向重排，标点跑到行首；字形缓存只按码点做键，同一字符的粗体和细体互相覆盖；亚像素定位被取整到整像素，小字号滚动时抖动；图集页切换时 UV 没留边距，采样到隔壁字形；字号动态变化后旧条目没失效，文字忽大忽小；布局线程和上传线程同时改图集，偶发整页花掉；一千个字形布局超过 2ms，对话框弹出卡一下。glyph_distance_field.py 的 GlyphDistanceField 得把 layout 和 upload 分开：缓存键带上字体、字重和字号，回退链按语言顺序查找，双向文本先重排再断行，图集按页分配并留采样边距，上传用原子切换避免读到半页，空串、零字号和负字号直接拒绝，输出每页占用和布局耗时。眼下十五条用例全红。

## 运行方式
```bash
python -m pytest tests -q
```
