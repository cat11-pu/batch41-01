# GSB Bugfix Task
## 题面
坐骑收藏版块的版主整理了一份长帖，把升阶前后对不上的地方一条条截了图。进化材料交上去阶数不动，返回的提示却是成功；手快连点，中间几阶被跳过，直接窜到顶阶；进阶后本该解锁的骑乘技能没出现，技能栏还是旧的；同一种坐骑养了两只，图鉴只点亮一个格子；速度加成和队伍光环叠在一起突破了上限，跑图比飞行坐骑还快；角色绑定的坐骑进化完变成账号绑定，邮件附件取不出来；预览里写的成功率是六成，结算用的却是另一张表；两个请求同时进化同一只，材料扣了两份只升了一阶；进化完成后等级被重置成一，之前喂的成长材料全白搭；正在骑乘时触发进化，角色卡在坐骑上无法下马，只能小退；放生后材料没有按投入返还，图鉴却依旧亮着。mount_evolution.py 的 MountEvolution 把 evolve、preview、feed、release、bind 分散在阶数、技能、外观、图鉴四张表上。希望阶数按状态机逐级推进，扣材料与升阶同事务，技能外观同时解锁，图鉴按物种去重，速度加成有硬上限，绑定规则前后一致，预览与结算同源，同一只坐骑加锁，进化保留等级，骑乘与进化互斥，放生按投入返还并熄灭图鉴。test_mount_evolution.py 的十五个断言跑了两遍，两次都断在同一处。

## 运行方式
```bash
python -m pytest tests -q
```
