# GSB Bugfix Task
## 题面
跨服排行榜按战区分片后，合榜时同一个人出现两次，名次还挨着。分片合并按角色名去重，同名不同区被吞成一个；分片写入有延迟，合并时漏掉刚更新的分数；分页游标用名次，合并后同一页重复或漏项；榜单缓存五分钟，玩家提升战力后看不到自己；同一玩家在两个分片都有记录，合榜后重复占位；赛季榜混进季前赛数据，老赛季分数还在；分片扩容后新分片从零开始，旧分片数据没有迁移过去；分片写入没有版本号，旧数据覆盖新数据；合并任务重跑，名次被重复计算；查询跨两个分片聚合，边界玩家被算两次；返回条数超过页大小，前端分页直接错位；角色已经删除，分片里还留着记录，合榜后出现在榜单上。rank_shard_merger.py 的 RankShardMerger 负责 submit、merge、rank、page 和 invalidate，各分片和全局榜各算一套名次。希望按全局角色编号去重，合并前等待分片水位，分页用稳定排序键做游标，缓存按版本失效，跨服唯一键，赛季维度隔离，扩容时迁移旧分片并回填水位，写入带版本比较，合并任务幂等，跨分片边界去重，分页做上限夹取。test_rank_shard_merger.py 的十五条检查现在全部失败，压重名合并、写入延迟、游标分页、缓存、跨服重复、赛季隔离、扩容迁移、版本覆盖、合并重跑、边界去重、页大小和幂等。

## 运行方式
```bash
python -m pytest tests -q
```
