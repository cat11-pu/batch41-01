# GSB Bugfix Task
## 题面
团本改复活锚点后，固定团灭一次就要多打半小时，客服每天都能收到进度错乱的申诉。灭团后全员在副本入口复活，锚点没有记录；锚点只记队长，换队长后队伍回到上一个点；首领战重置后小怪没重置，玩家跳过小怪直接打首领；释放灵魂后尸体留在首领房，复活出来卡在墙里；锚点激活和首领击杀不在一个事务，首领死了锚点还是旧的；普通和英雄难度共享锚点，切难度后进度被覆盖；掉线重连回到错误锚点，队友已经在尾王；锚点激活时有人不在副本，后来进本没有进度；灭团计时器和锚点绑定，计时结束前复活仍算灭团；拾取资格按进本时间算，中途加入的不能捡；副本重置后锚点没清，下一轮直接到尾王。respawn_anchor_book.py 的 RespawnAnchor 负责 activate、respawn、reset、bind 和 restore，锚点、首领击杀和拾取资格各写一份。希望锚点按副本实例和队伍持久化，队长变更不影响，首领重置带小怪，复活点做合法性校验，击杀和锚点同事务，难度维度隔离，重连读持久化进度，后进本同步当前锚点，灭团判定独立于计时器，拾取资格按击杀时名单快照，副本重置清空锚点。test_respawn_anchor_book.py 的十五个用例目前全红，压入口复活、队长变更、小怪重置、卡墙、事务、难度共享、重连、后进本、计时器、拾取资格、重置残留和合法性。

## 运行方式
```bash
python -m pytest tests -q
```
