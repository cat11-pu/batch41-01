# GSB Bugfix Task
## 题面
可破坏场景一炸墙，光追阴影和反射里还留着完整的旧墙，碎片飞出去后画面边缘一直闪；移动过的物体没有标脏，BVH 里还是上一帧的位置；只更新了叶子包围盒，父节点没往上合并，射线整段漏掉；零面积的退化三角形混进树里，遍历时除零；后台重建和前台遍历同时跑，射线读到一半新一半旧的节点，偶尔穿模；每帧重建预算超了就整帧放弃，光追结果直接消失；上万个小碎片按对象编号逐个更新，缓存命中率极低；实例化物体只改了实例变换，底层结构没动，影子还是旧的；删掉的物体节点没压缩，跑十分钟内存翻三倍；顶点里一个 NaN 把包围盒撑到无穷大，整棵树退化；射线起点落在包围盒内部时最近距离处理错，物体自相交出黑斑；每帧更新预算 2ms，现在要 9ms。bvh_refit_scheduler.py 的 BvhRefitScheduler 要协调 mark_dirty、refit、query 三个入口：脏标记按子树向上传播，包围盒自底向上合并，退化图元在构建时剔除，重建写新树、遍历读旧树，预算不够时优先保证可见性高的子树并记录降级，删除后做压缩，非有限顶点拒绝，输出更新节点数、压缩量和耗时。十五条用例现在一条都没跑通。

## 运行方式
```bash
python -m pytest tests -q
```
