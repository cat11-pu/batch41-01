# GSB Bugfix Task
## 题面
角色走上斜坡后，脚尖一半陷进地面，脚后跟悬空，下台阶时整个人一颠一颠；射线只从脚踝往下打，没考虑脚尖和脚跟，斜坡上必然穿地；左右脚各自解 IK，骨盆没有下沉，腿被拉到笔直；脚锁定用的是世界坐标，角色转身后没更新，脚在地上拖出一道；台阶边缘的射线打到侧面，脚被抬到墙面上；IK 迭代次数固定，膝盖偶尔反折；目标点超出腿长时直接钳死，脚悬在半空；上下坡切换没有平滑，骨盆每帧跳一下；被击退时脚锁没释放，腿扭成麻花；骨骼长度为零或目标点含 NaN 时没有拒绝；动画线程和物理线程同时改骨盆变换，偶发整条腿消失；二十个角色同屏时每帧预算 1ms，现在要 2.5ms。foot_ik_lock.py 的 FootIkLock 在 solve 和 release 之间没有状态机：脚底用前后两个采样点做射线，斜坡按法线对齐脚掌，骨盆按最低脚下沉并限制幅度，脚锁记录角色局部空间位置，台阶只接受朝上的面，膝盖极向量防反折，超距时逐步放脚而不是钳死，坡度变化做时间平滑，受击和死亡释放锁定，非法输入拒绝，骨盆写入原子化，输出每只脚的偏移和耗时。十五条用例目前一条也没过。
