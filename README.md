# GSB Bugfix Task
## 题面
足球游戏换上新动作库后，球员带球像在冰上滑：速度特征没有归一，一个冲刺速度就把朝向和角速度的权重全压掉；索引里删掉的旧片段还能被查到，切过去直接摆出已经废弃的射门姿势；镜像动作没有翻转特征，左脚球员的球被匹配到右脚动作；候选片段长短不一，混合时按固定一半权重，支撑脚在地上拖；连续两帧匹配到两个不同片段，没有滞回，动作来回抽搐；查询结果里包含当前正在播放的片段，角色自己和自己混；急停时轨迹预测窗口还按旧速度算，匹配到冲刺动作；片段首尾姿态没对齐，切换瞬间整个人跳一下；后台线程一边加载新片段一边查询，读到只写了一半的索引；动作库为空或只有一个片段时直接越界；一千个片段下单帧查询超过 1ms，比赛里明显掉帧。motion_match_index.py 的 MotionMatchIndex 现在只有 build、query、insert、remove 四个入口：特征按各自量纲归一，镜像片段带翻转标记，查询要排除当前片段并做滞回，候选按时间对齐后再给权重，索引读写用版本号隔离，空库和单条库走同一条路径，返回结果附带匹配代价和候选编号。眼下十五条用例一条也过不了。

