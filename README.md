# GSB Bugfix Task
## 题面
外包交来的一批角色模型导入引擎后全不对：角色只有一点八厘米高，站在场景里像蚂蚁，单位设置读的是文件默认值，没看资产自己的比例；有的模型躺在地上，有的背对镜头，美术说在 Blender 里是好的；Y 轴向上转 Z 轴向上的矩阵在根节点和网格节点各做了一次，模型被转了两次；把枢轴烘进顶点后又保留了节点变换，角色整体偏移半个身位；蒙皮的逆绑定矩阵没跟着单位缩放，骨骼一动画就散架；动画按二十四帧采样，三十帧素材动作慢了四分之一；多个节点共享同一个网格，单位修正只改了一份，另一份还是错的；树叶材质是双面的，导入后背面消失；场景有多个根节点，只导入了第一个，其余零件丢失；空节点和零缩放节点的法线矩阵求逆失败，出现 NaN；五个文件并行导入时共用全局单位状态，互相污染；五万节点的场景导入超过三秒。gltf_unit_fixup.py 的 GltfUnitFixup 目前把 inspect 和 apply 混在一次扫描里：单位按资产声明解析，轴转换只做一次，枢轴和节点变换二选一并记录，蒙皮矩阵跟随同一缩放，动画时间按源采样率换算，共享网格按引用去重修正，多根节点全部保留，奇异矩阵和空节点要报错，导入状态按文件隔离，输出节点数、修正项和耗时。目前这十五条用例一条都没过。

```bash
python -m pytest tests -q
```
