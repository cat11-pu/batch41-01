# GSB Bugfix Task
## 题面
新手引导改版后，新号第一天就卡在第三步，老号上线又被拉回去重走。断线重连回到第一步，已经完成的步骤全部重做；点跳过引导后，后续功能入口没有解锁；引导步骤可以乱序触发，先领了奖励再学操作；两个引导同时触发，界面叠在一起点不动；账号级引导和角色级引导混用，换个角色又要重走；同一步的引导奖励重复发；引导中强制退出，状态卡在中间，既不能继续也不能跳过；版本更新新增步骤，老玩家卡在旧步骤进不去；引导完成标记没落库，重启后又出现；跨服迁移后引导状态丢失；跳过条件只校验等级，不校验前置任务。tutorial_step_gate.py 的 TutorialGate 负责 start、advance、skip、resume 和 snapshot，步骤状态、奖励记录和账号标记分散在三个地方。希望步骤按状态机顺序推进，断线从持久化步骤恢复，跳过后统一解锁后续入口，乱序触发直接拒绝，引导之间互斥排队，账号级和角色级分层，奖励按步骤幂等，中断保留可恢复状态，版本升级做步骤迁移，完成标记落库，跨服迁移带引导状态，跳过校验前置条件。test_tutorial_step_gate.py 的十五个用例眼下没有一条通过，压重连回退、跳过解锁、乱序、引导叠加、账号角色混用、奖励重复、中断卡死、版本迁移、标记丢失、跨服、前置校验和状态机。

## 运行方式
```bash
python -m pytest tests -q
```
