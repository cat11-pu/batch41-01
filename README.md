# GSB Bugfix Task
## 题面
虚拟主播换了卡通模型后，一笑嘴角就裂到耳根，眨眼时两只眼睛一起闭死，说话时表情整个消失；源模型和目标模型的表情语义没做映射，张嘴被驱动到了嘴角；归一化和原始权重混着用，叠加后超过上限被硬截断，脸变成鬼脸；眨眼和眯眼共用同一组形状，眨眼时眼睛全闭；左右不对称的表情在镜像模型上反了，笑一边；表情层和口型层权重直接相加，说话时眉毛和嘴角都不动；目标模型缺少的形状被静默丢弃，半边脸没有反应；头部姿态和表情耦合，转头时嘴角被拉长；输入帧率低于渲染帧率时直接丢帧，表情一跳一跳；网络收到的表情帧和本地渲染不同步，偶尔读到写了一半的权重；空表情帧、全零权重和未知形状名没有处理；六十帧下表情重定向超过 1ms，直播开始掉帧。expression_retarget.py 的 ExpressionRetarget 把 map 和 blend 做成一步：按语义映射源和目标形状，归一化和原始模式分开，表情层和口型层按顺序混合并保持总和，缺失形状记录警告而不是丢弃，左右对称按模型朝向翻转，头部姿态从表情里解耦，低帧率输入做插值，共享权重用双缓冲，空帧和未知名字拒绝，输出每层权重和耗时。这十五条用例现在一条都过不了。
