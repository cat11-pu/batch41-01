# GSB Bugfix Task
## 题面
图鉴改成账号共享后，收集党发现点数一夜涨了两千，排行榜前面全是刚建的小号。同一件物品在两个角色各解锁一次，收集点数重复加；合服时图鉴进度直接覆盖，高进度被低进度冲掉；隐藏条目提前显示在列表里；追溯补发把已经领过的套装奖励再发一遍；收集套装奖励领完后条目被移除，套装效果却还亮着；赛季限定图鉴跨赛季还能点亮；账号图鉴和角色图鉴混算，转服后翻倍；图鉴缓存不失效，新获得的坐骑不进列表；批量补算全服玩家，在线战斗明显卡顿；图鉴排行榜和详情页用的不是同一份数据；坐骑放生后图鉴变灰，收集点数也被扣回去；图鉴点亮后转服，目标服显示未解锁，再点一次又重复加点。codex_collection.py 的 CodexCollection 负责 unlock、merge、grant、backfill 和 revoke，条目、套装和点数各算一份。希望账号和条目做唯一键，合服取并集，隐藏条目只在达成后显示，补发查领取记录，套装效果按当前点亮条目重算，赛季维度隔离，账号层和角色层分开，缓存按版本失效，批量分片限流，榜单和详情共用一份数据，图鉴点亮后永久保留。test_codex_collection.py 的十五个用例现在全部失败，压重复解锁、合服覆盖、隐藏、补发、套装失效、赛季、分层、缓存、批量、榜单一源、放生回退和唯一键。

## 运行方式
```bash
python -m pytest tests -q
```
