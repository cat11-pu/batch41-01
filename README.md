# GSB Bugfix Task
## 题面
音游自制谱面一导入就全偏，鼓点听着在正拍上，谱面却提前半拍；节奏检测把八分音符当成拍，BPM 显示一百二十八，实际是六十四；网格从音频第零秒开始铺，前奏有八小节空拍时整体错位；变速曲只取了一个全局平均 BPM，副歌变速后谱面越跑越远；判定延迟校准只调了判定线，没调节拍网格，打起来声音和谱面差一截；强拍检测把小节第一拍认成第三拍，重音全反；采样率转换后音频时长变了，网格时间没重算；低音很少的曲子检测阈值过高，整段一个 onset 都没有；网格用浮点累加，五分钟的曲子尾部漂了几十毫秒；静音文件、单声道反相和超短音频没有单独处理；分析线程还在写 BPM 表，界面已经读出来显示，偶发半张表；五分钟曲子分析超过两秒，导入要转圈。beat_grid_align.py 的 BeatGridAlign 现在分析完直接改全局表：onset 检测后做 BPM 倍频判断，相位用强拍投票，变速曲输出分段速度表，网格按采样点对齐而不是浮点累加，延迟校准同时作用于网格和判定，重采样后重算时长，静音和反相输入给出明确结果，并发读写用快照，输出 BPM、相位、分段数和耗时。这十五条用例眼下跑一遍全红。

