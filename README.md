# GSB Bugfix Task
## 题面
角色贴图切到 BC7 后，手机上看渐变背景出现一条条色带，头发透明边缘镶了一圈黑边；每个四乘四块独立算端点，块和块之间亮度对不上，放大后像马赛克；带 alpha 的图块用了不透明模式，半透明发梢被压成锯齿硬边；sRGB 贴图按线性空间算误差，暗部整体偏蓝；mip 链在压缩之后才生成，每级误差叠加，远处脸糊成一片；纯黑和纯白块的端点相同，解码时归一化除零，出现花点；法线贴图只压了 XY，重建 Z 没归一，光照方向错；低端机不支持 BC7 时没有回退格式，直接花屏；多线程同时编码同一张图集页，块写入交错，图集出现棋盘格；非四倍数尺寸的边缘块补边方式不一致，采样越界读到隔壁图；质量评估只看平均误差，色度偏差被亮度平均掉；一张 4K 图编码超过 200ms，打包窗口卡死。bc7_block_encoder.py 的 Bc7BlockEncoder 需要把 encode、decode、统计三块理顺：按 alpha 模式选块类型，端点搜索在 sRGB 感知空间做，mip 在压缩前生成，边缘块补边规则统一，图集页按块加锁保证多线程结果确定，不支持的格式给出回退，输出每页的错误统计和耗时。十五条用例现在一条都没通过。

## 运行方式

```bash
python -m pytest tests -q
```
