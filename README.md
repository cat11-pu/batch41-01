# GSB Bugfix Task
## 题面
社交组在做周报时发现亲密度总量的曲线不对，正常人涨得平缓，有一部分账号在两天里翻了好几倍，顺着查下去问题比想象的多。同一个好友一天内反复组队，每次退队再进都重新计一次加成；顶到上限以后本该写不进去，调用方拿到的却还是成功；删掉好友后对方的数值清零，重新加回来却把旧值一起带了回来；一区和二区显示的好友亲密度不一致，点开详情和列表又是两个数；组队加成取的是结算当刻的在线人数，不是进队那一刻的快照；等级奖励在跨天时重复弹出，同一个档位能领两次；双倍活动开启后，活动加成和道具加成叠乘，一天能刷出三天的量；衰减按登录时间算，一个月不上线的账号一点没掉；被拉黑的人还能通过组队继续刷；转服之后亲密度归零，历史等级奖励也查不到；排行榜和好友详情读的不是同一份数据；等级掉下去以后，之前解锁的组队加成没被收回，队伍面板还挂着高级效果。intimacy_ledger.py 的 IntimacyLedger 里 gain、decay、claim、block、transfer 各自保存亲密度、每日计数和奖励记录。希望每日获取按好友和日期幂等，写入时夹取上限，删好友按规则保留或清零并留标记，两区数值比对要带版本，组队加成取进队快照，等级奖励按档位幂等，活动加成单独乘区，衰减按世界时差计算，黑名单过滤，转服迁移完整数据，榜单和详情必须从同一处取数。仓库里那套社交用例跑到一半就全红了。

```bash
python -m pytest tests -q
```
