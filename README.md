# GSB Bugfix Task
## 题面
宝石镶嵌改成多色孔后，玩家发现宝石插进去背包里还在，摘下来又变成两颗。镶嵌成功后宝石没有从背包扣除；同色孔插入错颜色也能成功；摘除费用扣了，宝石没回到背包；宝石合成数量算错，三颗合成出来只有两颗；装备升级后孔位重置，镶嵌的宝石全部消失；两个请求同时插同一个孔，孔里出现两颗宝石；宝石属性叠加没有封顶，低等级宝石堆出超高属性；跨服装备宝石数据不同步，目标服看不到宝石；摘除绑定宝石后变成可交易；镶嵌预览显示的孔位和实际不一致；装备分解时宝石没有返还；同一颗宝石在两件装备的孔位都显示已镶嵌，摘除其中一件另一件也跟着消失。gem_socketing.py 的 GemSocketing 负责 socket、unsocket、merge、preview 和 salvage，背包、孔位和宝石属性各写一份。希望镶嵌和扣背包同事务，颜色和孔位严格校验，摘除费用与回包同事务，合成按配方数量结算，装备升级保留孔位和宝石，同一孔位加锁，属性加成封顶，跨服同步带版本，绑定状态随宝石继承，预览和结果同源，分解返还全部宝石。test_gem_socketing.py 的十五条检查现在全部失败，压宝石残留、颜色错插、摘除丢宝石、合成数量、升级清孔、并发双插、属性封顶、跨服、绑定、预览、分解返还和事务。

## 运行方式
```bash
python -m pytest tests -q
```
