# GSB Bugfix Task
## 题面
排位晋级赛改成三局两胜后，玩家发现同一场胜利被算成两胜，晋级像坐火箭。晋级赛胜场重复计算，同一场对局结算了两次；失败后晋级赛没有重置，下一场直接接着打；晋级赛期间段位发生变化，匹配到的对手还是按旧段位；掉线判负但晋级赛进度没有扣；晋级赛跨赛季没有结算，新赛季还挂着旧进度；免晋级卡用了没生效，卡却没了；晋级赛连续匹配到同一个对手三次；晋级赛结果和普通对局结果双写，胜负记录对不上；晋级赛保护期过了还能继续享受保护；玩家主动放弃晋级赛后冷却没生效；跨服迁移后晋级赛进度丢失；晋级赛进行中服务器重启，进度回到上一场，客服只能手工补。rank_promotion_series.py 的 PromotionSeries 负责 start、record、advance、settle 和 abort，场次记录、段位快照和保护状态各存一份。希望每场对局按编号幂等，失败后按规则重置，开赛时冻结段位快照，掉线判负也计入进度，赛季边界强制结算，免晋级卡原子消费，同一轮对手去重，结果只写一处，保护期按绝对时间，放弃写冷却，跨服迁移带进度。test_rank_promotion_series.py 的十五条检查现在全挂，压重复胜场、失败重置、段位快照、掉线判负、跨赛季、免晋级卡、对手重复、双写、保护期、放弃冷却、跨服迁移和幂等。

## 运行方式
```bash
python -m pytest tests -q
```
