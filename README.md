# GSB Bugfix Task
## 题面
仲裁组批了一张排位赛的回滚单，执行完玩家又提交了第二张，说段位是回来了，别的东西全乱套。回滚脚本只把段位分写回去，赛季奖励邮件和成就进度停留在判负那一版；原来发出去的奖励没有作废，玩家在回滚之后又领了一次；这张单子跨了赛季，旧赛季的分数被直接写进新赛季的档案；队伍里只处理了申诉人，另外四个人的战绩还是败场；回滚和玩家登录撞在一起，旧缓存把刚写回的数据又盖了回去；脚本中断后重跑，扣回的金币扣了两遍；战绩页和录像还是旧结果，玩家拿着截图继续投诉；奖励物品早被交易或分解，没法原样放回背包；补偿邮件跟着回滚一起发，同一个人前后收了两封；操作没有留下审计记录，值班同学查不到是谁执行的；回滚完成后隐藏分没有重算，下一局仍按败场匹配。match_state_rollback.py 的 MatchStateRollback 分 plan、apply、revert、compensate、audit 五步，段位、奖励、任务和战绩分散在四处。我希望能按对局编号去重，把段位、奖励、邮件、任务、成就和隐藏分存成同一个回滚点，跨赛季的单子直接拒绝或转成补偿，整队处理保持原子，回滚期间冻结登录并让缓存失效，重跑要能去重，展示层读同一份结果，已经消耗的物品按价值折算，补偿与回滚互斥，全程留痕，隐藏分按新结果重算。test_match_state_rollback.py 十五项检查我挨个试过，全部挂在那里。

## 运行方式
```bash
python -m pytest tests -q
```
