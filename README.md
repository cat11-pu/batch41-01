# GSB Bugfix Task
## 题面
合服迁移做到一半，运维发现源服还能写，目标服已经有人上线，两边的背包对不上。迁移开始后源服没有冻结，玩家又打了一件装备；迁移任务重复提交，目标服生成两份角色数据；切换瞬间有未提交事务，源服扣了物品，目标服没有收到；增量日志按时间戳重放，后发生的操作被先应用；迁移进度只记批次不记批次内偏移，重启后整批重复写；校验和只算角色表，不算背包、邮件和公会仓库；回滚拿旧快照覆盖，迁移后新产生的数据全丢；登录令牌没失效，玩家切回源服继续操作；迁移期间拍卖托管和邮件被两边同时处理；目标服写入成功但源服标记失败，重试造成物品复制；迁移完成后源服只读没解除，玩家一直登不进去。merge_cutover_ledger.py 的 MergeCutover 负责 freeze、copy、replay、commit、rollback 和 verify，快照、增量日志和切换标记各写各的。希望迁移开始即冻结源角色，迁移编号全局幂等，快照加增量水位按序重放，检查点精确到批次内偏移，校验和覆盖全部玩家数据，回滚按操作日志补偿而不是覆盖快照，令牌在切换时失效重签，拍卖和邮件在迁移期冻结，切换走两阶段提交或发件箱，完成后解除只读。test_merge_cutover_ledger.py 的十五个用例现在没有一条能过，压源服写、重复提交、未提交事务、重放顺序、批次偏移、校验范围、回滚丢数据、令牌、托管并发、切换补偿、只读解除和幂等。

## 运行方式
```bash
python -m pytest tests -q
```
