# GSB Bugfix Task
## 题面
离线收益改成按最后下线时间结算后，玩家发现挂一个月能领一年的资源。离线时长从登录时刻算，不是从最后下线时刻；收益上限没有生效，离线越久领得越多；双倍收益卡在离线期间使用，结算时没有乘；两台设备同时点领取，各领一份；跨天重置把还没领的收益清掉；离线收益按当前队伍算，不是下线时的队伍快照；服务器维护时间也算进离线，维护补偿还另发一份；收益邮件过期，玩家上线时已经领不了；离线期间角色被踢出公会，收益仍按公会加成算；把系统时间往回拨能反复刷收益；收益明细和实际入包数量对不上；领取时背包满，收益被标记已领但物品没进包，客服补发又触发重复领取。offline_earnings.py 的 OfflineEarnings 负责 mark_offline、settle、claim、expire 和 snapshot，下线时间、收益快照和领取记录各写一份。希望以最后下线时刻为基准，收益上限在结算时夹取，双倍卡按下线时状态快照，领取按角色和时间窗幂等，跨天保留未领收益，队伍和公会加成取下线快照，维护时段从离线时长里扣除，邮件有效期从发放时刻算，时间回拨直接拒绝，明细和入包同事务。test_offline_earnings.py 的十五个用例眼下全红，压离线起点、上限、双倍卡、双设备、跨天、队伍快照、维护、邮件过期、公会、时间回拨、明细、幂等和事务。

## 运行方式
```bash
python -m pytest tests -q
```
