# GSB Bugfix Task
## 题面
沙尘暴和落叶特效一开，粒子穿地、卡墙、堆在墙角自己抖，风场设成零也停不下来；高速粒子按上一帧位置查碰撞，薄地面直接穿过去；碰撞法线取的是三角形面法线，斜坡上粒子顺着坡滑走而不是停住；空间哈希的格子大小写死，粒子半径大于格子时整片漏碰撞；同一粒子一帧内撞到两个面，速度被反复反射，原地抖动；粒子死亡后还留在哈希桶里，新粒子查到幽灵碰撞；多个 worker 并行写空间哈希没有同步，桶链断掉，偶发穿模；材质摩擦和弹性表缺项时直接除零，粒子速度变成 NaN；粒子被墙和地同时夹住，位置修正左右弹；碰撞预算 2ms，超了就整批跳过，沙尘全穿地；半径是负值或位置含 NaN 的粒子混进哈希，污染整桶；粒子正好落在三角形边上时归属不稳定，两帧结果不一样。particle_collision_field.py 的 ParticleCollisionField 要按速度做子步连续检测，碰撞法线按邻接面平滑，哈希格子按最大粒子半径推导，死亡粒子及时清理，并发写入用分桶锁或双缓冲，材质表缺项回退默认值，超预算按重要性降级并报告，非法半径和位置直接拒绝，输出碰撞对数、子步数和耗时。眼下十五条用例全部是红的。

## 运行方式

```bash
python -m pytest tests -q
```
