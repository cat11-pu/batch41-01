# GSB Bugfix Task
## 题面
举报系统接进审核后台后，一个玩家一天被封了三次又解了三次，客服主管亲自来问怎么回事。同一场对局十个人举报，生成十条工单，审核员重复处罚；证据只存最近二十条聊天，战斗日志和语音没有快照；审核通过后举报人没收到结果，客服被追问；误封申诉期间封禁到期自动解，申诉单还挂着；批量审核把不同案件合并成一个结论，处罚对象错；举报冷却按举报人算，换个小号继续刷；恶意举报不扣信誉，举报榜第一全是乱报；跨服举报找不到被举报角色，工单一直待处理；审核结论回写延迟，同一案件被两个审核员各罚一次；申诉改判后原处罚没撤销，玩家两头挨罚；证据截图过期清理后，申诉无法复核。report_review_queue.py 的 ReviewQueue 负责 file、assign、decide、appeal 和 enforce，工单状态和处罚状态没有联动。希望同对局同被举报人聚合工单，证据快照包含聊天、战斗和语音摘要，结论通知举报人，申诉冻结处罚到期，批量按案件独立处理，冷却按被举报人算，恶意举报扣信誉，跨服用全局编号，结论带幂等键，改判撤销原处罚，证据保留期不短于申诉期。test_report_review_queue.py 的十五个用例眼下全红，压重复工单、证据快照、通知、申诉冻结、批量合并、冷却、恶意举报、跨服、回写延迟、改判和证据保留。

## 运行方式
```bash
python -m pytest tests -q
```
