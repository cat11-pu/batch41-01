# GSB Bugfix Task
## 题面
VR 建筑漫游戴上头显后，左右眼画面明显错位，看近处柱子有重影；双眼投影矩阵用了同一个瞳距，左右眼没有水平偏移；单趟实例化渲染的视图顺序反了，左右眼内容互换，立体感全无；视锥剔除只按中间那一个视锥做，边缘的墙一转头就弹出来；姿态没有晚锁，转头时画面拖半帧；近平面按单眼设置，双眼重叠区出现一条裁剪缝；重投影用的是上一帧深度，遮挡边缘出现黑洞；瞳距填零或负数时没有回退，画面直接糊成一片；分辨率切换后视口没重算，画面被压扁；左右眼共用一张阴影图，阴影偏移不一致，近处阴影一只眼有一只眼无；一帧预算 11ms，超时降分辨率但没通知上层，画面突然变糊；渲染线程读姿态时姿态线程正在写，偶尔读到撕裂的矩阵。stereo_view_plan.py 的 StereoViewPlan 每次 plan 都重算一遍双眼数据：每眼独立的视图和投影，单趟渲染的视图索引固定，剔除用两眼视锥的并集，姿态在帧末原子读取并做晚锁，重投影按深度做遮挡校验，瞳距非法时回退默认值，视口随分辨率重建，阴影按眼偏移，预算超限返回降级标记，输出双眼矩阵和耗时。这十五条用例眼下没有一条通过。
