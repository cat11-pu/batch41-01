# GSB Bugfix Task
## 题面
老片重制把二十三点九七六帧转成二十五帧，字幕越往后越早，片尾提前了十几秒；换算时把二十三点九七六当成二十四算，九十分钟下来差了好几秒；丢帧时间码没处理，每到整分钟字幕就跳一下；每条字幕单独四舍五入，误差一条条累积，最后一条偏出半秒；帧率变快后字幕显示时长没跟着缩，长句尾巴被下一句顶掉；原本相邻的两条字幕重定时后变成负间隔，播放器直接跳过一条；强制字幕和普通字幕混在一起重定时，外语注释跑到画面上方；偏移量按毫秒加但时间基是帧，单位混着用，偏了整整一倍；片尾字幕超出视频长度没有裁切，导出时报错；可变帧率段落按平均帧率算，动作戏字幕全错位；批量处理十个字幕文件时共用全局帧率，不同项目互相污染；一万条字幕重定时超过两百毫秒。caption_retime.py 的 CaptionRetime 现在把换算和校验分成两遍扫描：源帧率和目标帧率用有理数表示，按源时间轴逐条映射而不是累加误差，支持丢帧时间码，可变帧率按段表换算，时长按比例缩放但保留最短显示时间，超出片长裁切并记录，强制字幕单独标记，负时间和零时长报错，批量任务按项目隔离，输出偏移量、裁切数和耗时。这十五条用例现在没有一条能过。
