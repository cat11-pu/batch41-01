# GSB Bugfix Task
## 题面
播客 App 上了 1.5 倍速后，听众反馈人声发闷、句尾吞字，笑声被拉成两截；固定分析窗做变速，倍率一变帧重叠就错，出现金属味的颤音；拍桌子和爆破音被当成周期信号拉伸，瞬态糊成一片；输出长度用浮点累加，十分钟后和理论值差出几百个采样，结尾被截；拖动进度条后相位没重置，开头咔一声；静音段被过度拼接，呼吸声重复两遍；左右声道各自对齐，鼓声的声像左右飘；先变速再重采样，音高跟着变了；倍率填零或负数时没有拒绝，直接死循环；短于一个分析窗的音频一进来就数组越界；边解码边变速时环形缓冲读写竞争，偶发整段静音；实时 1.5 倍速单核占用冲到百分之四十。time_stretch_wsola.py 的 TimeStretchWsola 得先给出 plan 再执行 process：分析窗和重叠随倍率推导，瞬态检测后跳过拉伸，输出样本数按有理数精确计算，seek 时重置相位并预卷，静音段降低拼接强度，多声道共用同一组对齐偏移，变速和重采样的顺序固定并给出音高补偿，非法倍率和过短输入拒绝，环形缓冲用读写指针原子交换，输出倍率、延迟和耗时。十五个用例现在跑起来全是红的。

## 运行方式
```bash
python -m pytest tests -q
```
