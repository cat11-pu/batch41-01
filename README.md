# GSB Bugfix Task
## 题面
骑行视频开防抖后，画面边缘像果冻一样扭，过减速带时地平线还会突然歪一下；陀螺仪时间戳和视频帧没对齐，补偿晚了一帧，抖动反而被放大；滚动快门按行曝光，整帧只用一个矫正矩阵，快速摇镜时画面撕裂；裁切比例写死，大颠簸时四角露出黑边；地平线锁定用了重力方向但没做低通，刹车点头时地平线跟着跳；平滑窗口按帧数算，三十帧和六十帧素材防抖强度完全不一样；陀螺仪丢了几帧就补零，画面瞬间歪掉再弹回；广角畸变没校正就防抖，画面边缘被拉长；裁切后分辨率是奇数，编码器直接拒绝；陀螺仪零偏没估计，长时间录制画面缓慢旋转；防抖线程读环形缓冲时写入指针已经绕圈，读到上一秒的数据；4K 三十帧每帧预算 8ms，现在要 15ms。gyro_stabilize.py 的 GyroStabilize 把 calibrate 和 plan 放在同一帧里做：陀螺仪和帧时间按共同时钟对齐，滚动快门按行时间求解，裁切比例随抖动幅度自适应并保证无黑边，地平线用低通重力估计，平滑窗口按时间不按帧数，丢帧按角速度外推，先做畸变校正再防抖，输出宽高强制偶数，长时间录制估计零偏，环形缓冲用序号校验，超预算降精度，输出裁切比例和耗时。现有十五条用例目前都是红的。

