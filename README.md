# GSB Bugfix Task
## 题面
证书校验、动态口令和审计时间戳都依赖系统时间，上个月一台机器的时间跳了两个小时，出了一串连锁故障。时间跳变后已经过期的证书仍然通过校验，因为校验逻辑用的是单调时钟；时间回拨让审计日志出现倒序，链条校验直接失败；NTP 服务不可达时时间自由漂移，没有任何告警；闰秒那一刻动态口令窗口计算溢出，整批用户验证失败；多个上游时间源偏差五秒，选的是响应最快而不是最可信的那个；系统启动时时间还没同步就对外提供服务；时间跳变导致定时任务在几分钟内重复执行；容器共享宿主机时钟但时区不同，日志时间全乱；校时过程中取到的时间戳既不是旧值也不是新值；偏差超过阈值只记一条日志，不拒绝任何请求。ntp_skew_guard.py 的 ClockSkewGuard 要解析 NTP 响应并计算偏差和往返延迟，按层级和稳定性选可信源，检测墙钟跳变并与单调时钟分离，启动未同步时拒绝敏感操作，闰秒做钳制，阈值外的请求直接失败，时间戳读取保证原子性，审计记录每次校时。test_ntp_skew_guard.py 的十五个用例目前全部失败，覆盖证书过期、日志倒序、源不可达、闰秒、源选择、启动未同步、任务重复、容器时区、读取撕裂、阈值放行、空响应、负延迟、跳变检测、校时审计和状态隔离。

## 运行方式
```bash
python -m pytest tests -q
```
