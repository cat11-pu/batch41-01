# GSB Bugfix Task
## 题面
几个团队共用一个强制访问控制策略仓库，合并工具最近把两个服务的权限放大了，审计直接给了高危。两个同名配置合并时，后加载的把前一个整个盖掉，连拒绝条目都没了；通配路径能匹配到带上级目录穿越的写法；拒绝条目写在允许条目前面，被后面的允许规则盖掉；两个配置都定义了同名子域，后加载的把前一个整个替换，子规则丢失；变量值里带空格，展开后被拆成两条；文件条目带尾斜杠只匹配目录，配置本意是文件和目录都要；网络条目只写了协议族，没有限制端口；子配置的跳转指向一个不存在的目标，运行时才报错；编译缓存命中了旧版本，策略更新一直不生效；未知条目类型只打警告，整个片段被丢掉。apparmor_policy_compile.py 的 ProfileMergeCompiler 要解析配置语法，保留每条规则的来源标记，正确处理变量展开和转义，按顺序与优先级合并同名配置，通配匹配前先做路径规范化，校验跳转目标存在，网络规则补全协议和端口语义，缓存键包含全部输入，未知规则按错误处理。那十五项检查跑一遍挂一遍，没一次例外。

## 运行方式
```bash
python -m pytest tests -q
```
