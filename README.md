# GSB Bugfix Task
## 题面
开放平台把第三方应用接入改成自助注册以后，安全巡检连着挑出几处不该放行的登记。回调地址填成明文协议的也通过了，授权结果会被旁人截走；同一个应用名连提四次，后台留下四个编号，前三个密钥居然还能用；公共类型的应用仍然拿到了一份密钥；授权方式勾了机器对机器，却没有配任何接口范围，签发出来的令牌能调全部业务；注册凭据按编号查询，知道编号就能读到密钥；上传的图标地址指向内网网段，预览服务直接把请求打进了元数据接口；同一个软件标识并发提交，最后落下两个客户端；注册成功的响应把密钥回显到页面，还整段写进访问日志；删掉应用以后，之前发的刷新凭证还能继续换令牌。oauth_client_registration.py 的 DynamicClientRegistry 要逐项卡住：回调地址逐字比对，只收加密协议和本机回环，片段和通配一律拒绝，端口先归一；公共类型不签发密钥；授权方式与接口范围成对出现并走白名单；注册凭据绑定客户端编号且可轮换；软件声明要验签并看有效期；所有地址字段做协议与主机白名单，内网直接拒绝；同一软件标识重复提交要幂等；删除应用时吊销它名下全部凭证。测试里列了十五项，现在一条都过不了。

## 运行方式
```bash
python -m pytest tests -q
```
