# GSB Bugfix Task
## 题面
短视频剪辑器更新后，运营拖片段时吸附点乱跳：明明对着前一段的尾巴，松手却差了半帧；磁吸轨道上删掉一段，后面的视频整体前移，字幕轨却留在原地；轨道分组折叠后拖动整组，组内片段仍按折叠前的坐标吸附，整组偏出三秒；转场占用了前后片段各一半时长，重叠检测没把转场算进去，导出首尾各少一帧；撤销一次回不到原位，要按两次；时间线缩放到最小时，像素换时间用整数除法，长视频尾部越拖越偏；音频波形吸附点和视频帧边界对不上，声画差半帧；片段能被拖到负时间，导出时直接报错；多选拖动时每个片段各自吸附，原本对齐的间距全乱了；锁定的轨道仍然参与吸附，拖不过去；后台转码完成回调改时间线时，前台正在拖动，偶发片段消失；五百个片段拖动时每帧超过 16ms，明显卡手。timeline_snap_engine.py 的 TimelineSnapEngine 把 snap、move、ripple、undo 四件事挤在一个状态下：吸附统一落在帧网格，分组折叠时统一换算到时间线坐标，转场作为独立区间参与重叠判断，磁吸移动带上关联轨道，撤销记录前后完整状态，缩放换算用有理数，锁定轨道排除吸附，禁止负时间，多选保持相对间距，时间线修改串行化，输出吸附点和耗时。眼下这十五条用例没有一条跑得通。
