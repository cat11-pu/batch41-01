# GSB Bugfix Task
## 题面
安全团队用脚本批量下发 SELinux 布尔值和策略模块，结果两台机器重启后行为完全变了。setsebool 带了持久化参数，运行时值和磁盘上的值却不一致，重启直接回退；布尔名大小写或者下划线写法不同，脚本当成新名字静默忽略；低优先级的策略模块被高版本覆盖，加载命令却返回成功；permissive 域在 enforcing 主机上照样放行，没人发现；relabel 只改了顶层目录，子文件的上下文还是旧的；模块卸载后类型仍被别的模块引用，系统处于半残状态；两个模块并发下发，先加载的把旧类型锁住；布尔值之间的依赖关系没有校验，开了 A 却没开它依赖的 B；审计只记布尔名，不记旧值和新值；遇到不认识的布尔值默认按 true 处理。selinux_boolean_gate.py 的 SelinuxBooleanGate 要区分持久值和运行时值，布尔名先归一，模块按优先级和版本比较，permissive 域单独判定，relabel 递归到子项，卸载前检查类型引用，并发下发加锁，校验布尔依赖，审计记录旧值新值，未知布尔值按失败关闭。test_selinux_boolean_gate.py 的十五个用例目前全部失败，分别压持久化回退、名称变体、模块覆盖、permissive 放行、递归遗漏、卸载残留、并发锁、依赖缺失、审计旧值、未知布尔、空模块、重复加载、版本回退、上下文冲突和结果隔离。

## 运行方式
```bash
python -m pytest tests -q
```
