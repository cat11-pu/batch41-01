# GSB Bugfix Task
## 题面
账号中心最近开放用户自助改邮箱和手机号，上线一周就接到两起账号被盗的投诉，都是改绑环节出的问题。新邮箱填完立刻生效，旧邮箱连一封通知都没收到；新邮箱的验证令牌可以反复使用；令牌三十天都不失效；改绑期间旧会话的令牌照样能登录；用户并发提交两个新邮箱，最后一个覆盖前一个，两封验证信都发了出去；冷却期内可以无限次改绑；改绑成功以后备用恢复码没有失效；管理员后台代改完全绕过冷却；同一个邮箱只是大小写不同，被当成新邮箱；验证链接换一个浏览器打开也能通过，根本没绑会话。contact_change_hold.py 的 ContactChangeHold 要先给旧地址发通知，再对新地址做双确认，令牌一次性并设短有效期，改绑走事务并让旧会话和恢复码一起失效，冷却期按账号维度计算且管理员路径同样受限，邮箱统一小写做规范化，验证动作必须绑定发起时的会话，每一步写审计。test_contact_change_hold.py 的十五个用例现在全部失败，覆盖旧地址通知、令牌复用、超长有效期、旧会话、并发提交、冷却绕过、恢复码、管理员路径、大小写、跨浏览器、空地址、重复确认、事务回滚、审计和状态隔离。

## 运行方式
```bash
python -m pytest tests -q
```
