# GSB Bugfix Task
## 题面
主机基线扫描连续几轮漏报，安全评审拿一个自己编译的提权程序就绕过去了。包管理器升级后新装的提权位文件不在基线里，工具只比路径不比 inode，文件被替换也看不出来；cp 保留了安全扩展属性，扫描只看权限位，带能力的普通文件被放过；挂着 nosuid 的分区上，人人可写的目录照样报高危，误报把值班同学折腾得够呛；硬链接让同一个 inode 出现两条路径，豁免规则只匹配到其中一条；容器镜像层里的文件被宿主扫描当成真实文件；豁免规则写成 /usr/bin/*，新塞进去的后门一起被豁免；文件被替换但修改时间特意保留，基于时间的漂移检测失效；能力集合本来与顺序无关，实现却按字符串直接比较；扫描途中文件被删，整轮任务直接中断；审计只记路径，不记内容哈希和能力集合。suid_capability_baseline.py 的 SuidCapabilityBaseline 要以 inode 加内容哈希建立基线，解析扩展属性里的能力集合并按集合比较，识别 nosuid 挂载，硬链接按 inode 去重，排除容器与叠加文件系统路径，豁免规则要求精确匹配，用内容哈希发现替换，缺失文件跳过而不是中断，审计记录哈希和能力集合。我拿十五项检查跑了两轮，两轮都在同一个地方崩。

## 运行方式
```bash
python -m pytest tests -q
```
