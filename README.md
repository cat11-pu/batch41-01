# GSB Bugfix Task
## 题面
室内侦探关卡一开环境光遮蔽，家具底下出现一圈黑雾，墙角接触阴影一闪一闪；深度重建世界位置用错了投影矩阵，斜着看时遮蔽整体偏移半米；法线从深度差分出来，物体边缘法线翻转，墙角出现硬黑边；采样核在切线空间旋转但没做蓝噪声平铺，墙面出现重复的颗粒图案；遮蔽半径按屏幕像素写死，换到 4K 后接触阴影缩成一条线；半分辨率结果升采样用双线性，桌腿边缘漏光，背景亮进来；时域累积没做深度和法线校验，角色走过留下拖影；天空像素也参与计算，远景蒙上一层黑雾；深度是远平面零值时除零，整屏变成 NaN；分屏两个视口共用历史缓冲，左右画面互相污染；遮蔽强度调成零仍然全屏跑一遍；1080p 下 4ms，超出预算一倍。ssao_kernel_rotate.py 的 SsaoKernelRotate 要从深度和法线重建位置，半球采样按世界半径换算，噪声按像素平铺并旋转采样核，升采样用深度感知的双边权重，历史帧按深度和法线拒绝，天空和远平面剔除，非法深度走安全分支，每个视口独立，强度为零直接短路，超预算降采样并记录，输出遮蔽值、采样数和耗时。十五条用例现在一条都跑不绿。

## 运行方式
```bash
python -m pytest tests -q
```
