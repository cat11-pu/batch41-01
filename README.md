# GSB Bugfix Task
## 题面
赛车游戏跑到黄昏隧道段，玩家反馈隔着水泥墙也能看见太阳的光斑，车头一转，鬼影在屏幕上乱跳。遮挡判断只测了光源落在屏幕上的那一个点，墙后的光斑照样透出来；遮挡缓冲降采样后按最近深度取值，隧道口的细栏杆完全挡不住光；光斑的大小直接绑在像素数上，视场角从七十拉到一百一，比例还是老样子；宽银幕下横向拉丝没有按宽高比校正，拉丝方向跟着窗口一起变；三盏路灯的光斑按数组顺序叠加，数组一重排亮度就变了一档；鬼影层没有按远近排序，近处的鬼影盖住了更远的光源；相机钻进隧道时没有淡出，光斑硬切一下消失；光源转到相机背后仍然被算进去，投影之后出现非法坐标；窗口从全高清拉到带鱼屏，光斑用的渲染目标没有重建，位置整体偏掉；分屏双人模式共用一张遮挡缓冲，右半边用了左半边的可见性；每帧全屏查询耗时三毫秒，比给的时间多出一倍。lens_flare_occlusion.py 的 LensFlareOcclusion 要用多点保守可见性采样，按视场角和宽高比校正尺寸与拉丝方向，鬼影按远近排序，进出遮挡物时平滑淡出，相机背后的光源直接剔除，每个画面独立持有缓冲，尺寸变化重建目标，时间不够就降低采样密度并留记录，返回可见度、光斑坐标和采样数。这套逻辑配了十五项检查，眼下全部不过。

## 运行方式
```bash
python -m pytest tests -q
```
