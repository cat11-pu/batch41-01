# GSB Bugfix Task
## 题面
大世界分线改成动态合线后，玩家在跨线打世界首领时人和仇恨都留在了原地，宠物也找不到。跨线时宠物和召唤物留在原线，角色成光杆；同一玩家在两条线各有一个实体，都能被攻击；切线后技能冷却重置，玩家靠切线无限放大招；跨线交易导致物品复制，两条线各有一份；分线人数统计滞后，明明满了还能进；首领跨线后仇恨不清，原线玩家继续被点名；跨线邮件延迟，附件在两线之间丢；切线失败卡在加载界面，重登回到旧线但状态是新线的；合线时掉落归属按合线后的队伍算，原线玩家白打；跨线后公会频道断，要重登才恢复；分线切换和下线同时发生，角色数据双写；跨线后任务追踪还指向原线坐标，自动寻路把角色往反方向带。world_line_handoff.py 的 WorldLineHandoff 负责 transfer_in、transfer_out、merge、recover 和 aoi，实体迁移和角色数据写入分开提交。希望实体迁移带宠物和召唤物，角色加全局唯一锁，冷却按绝对时间，物品锁跨线，人数统计实时，仇恨随实体迁移，邮件跟随角色，失败回滚到源线，掉落归属按伤害快照，频道重订阅，下线和切线互斥。test_world_line_handoff.py 的十五条用例眼下全部失败，压宠物、双实体、冷却、复制、人数、仇恨、邮件、失败回滚、掉落、频道、双写和唯一锁。

## 运行方式
```bash
python -m pytest tests -q
```
