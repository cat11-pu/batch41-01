# GSB Bugfix Task
## 题面
全屋音响加了多房间同步后，客厅和厨房差半拍，走到走廊能听出两边的错位，十分钟后差出两百毫秒；每台设备按本地时钟播放，晶振漂移没估计；主机时钟偏移只用一次往返采样，网络一抖偏移就错；蓝牙音箱的额外延迟没标定，永远固定落后一截；暂停再恢复只发命令不带时间戳，恢复后两边错位；新设备入组或离线重连后直接从最新位置跳播，没算缓冲也不追帧；四十四点一千赫兹和四十八千赫兹的设备混用，重采样后时长慢慢漂；某台设备丢包重传后缓冲变深，没有追赶或等待策略；主机切换后新主机沿用旧偏移，所有房间一起跳；从机时钟回拨或跳变时没有平滑，直接爆音；多台设备同时上报时钟，主线程读到更新一半的表，偏移偶发错乱；五十台设备每 100ms 同步一轮，CPU 占用超过百分之五。multiroom_clock_sync.py 的 MultiroomClockSync 要估计每台设备的时钟偏移和漂移，延迟标定覆盖蓝牙和功放，播放位置按统一时间轴映射，暂停恢复带时间戳，入组先填缓冲，重采样对齐采样率，缓冲过深的设备限速追赶，主机迁移平滑交接，异常时钟做渐变更正，时钟表用快照读取，超预算降频并记录，输出偏移、漂移和缓冲深度。十五条用例眼下全红。

## 运行方式
```bash
python -m pytest tests -q
```
