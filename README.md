# GSB Bugfix Task
## 题面
VR 恐怖游戏里，怪物在右后方低语，玩家却一直往左前方找；一转头，声音又黏在耳朵边上不跟着场景走；ITD 只按方位角查表，仰角变了延迟不变，头顶的滴水声听着像在正前方；HRTF 数据只有五度间隔，相邻扇区切换时爆音；头显姿态更新后没重算声源相对方位，声像跟着头转；近场距离衰减和 HRTF 增益叠着算，贴脸的音效直接爆音；四十四点一千赫兹的 HRTF 用在四十八千赫兹的引擎里，音高和延迟都不对；双耳输出接到单声道设备时只取了左耳；声源从右侧穿到左侧时方位角翻转，左右耳瞬间互换；环境声解码顺序错，前后声道反了；并发更新头部姿态时音频线程读到半更新矩阵，声像瞬间跳到后脑；三十二个声源同时卷积，单核占用冲到百分之八十，开始随机丢声音。hrtf_panner.py 的 HrtfPanner 目前把听者姿态和声源计算绑死：按方位和仰角查表并插值，ITD 和 ILD 分开计算，头部姿态原子读取，近场单独补偿不与距离衰减重复，采样率不一致时重采样 HRTF，单声道设备做下混，跨头时按最短路径插值，非法角度拒绝，超预算按优先级降级并报告，输出每声源增益和耗时。目前十五条用例全是红的。

## 运行方式
```bash
python -m pytest tests -q
```
