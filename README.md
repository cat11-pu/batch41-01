# GSB Bugfix Task
## 题面
内部 CA 换成 ACME 自动续期以后，上周一批服务证书同时过期，排查发现订单状态机根本没走对。订单还在 processing 就去下载证书，拿回来的是空链；nonce 复用触发大量 badNonce，重试风暴把 CA 限流；授权已经 valid，订单却一直停在 pending，轮询永远不结束；多域名订单只完成一个授权就 finalize，其余域名没签进去；CNAME 委托只查第一跳，第二跳指向未授权区域也能过；续期窗口按签发时间算，九十天的证书第三十天就开始续，任务永远在跑；两个实例并发续期，后写入的旧证书覆盖了新证书；下载回来的证书链顺序错误，中间证书缺失；账户密钥轮换后，旧订单还拿旧 key 签名；域名因为违规被吊销，自动续期又把同一域名签了回来。acme_order_renewal.py 的 AcmeOrderRenewal 要维护订单、授权和挑战的状态机，nonce 池一次性消费并按失败退避，多域名必须全部 valid 才允许 finalize，CNAME 链逐跳校验，续期窗口按到期时间计算，同一证书续期加单飞锁，证书链按叶子到中间的顺序组装，账户密钥编号参与签名校验，吊销黑名单命中时拒绝续期。test_acme_order_renewal.py 的十五个用例现在全部报错，覆盖提前下载、nonce 重放、订单卡住、多域名缺签、CNAME 越权、续期过早、并发覆盖、链序错误、旧密钥、吊销复签、空订单、挑战超时、授权失效、重复 finalize 和结果隔离。

## 运行方式
```bash
python -m pytest tests -q
```
