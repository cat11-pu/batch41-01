# GSB Bugfix Task
## 题面
动画组把动捕棚的数据离线压成运行时格式，新一批跑酷和攀爬片段进游戏后动作全变形：同一个转身，角色上半身拧成麻花，手臂还会反折；量化时四元数选了最小的三个分量，但符号没统一，q 和负 q 解出来是反向旋转；最大分量的两位索引在末端指骨上溢出，重建后指骨接到错误的父级；平移范围按整套骨架统一取值，矮个子角色的手抖，高个子角色的脚被拉长；缩放通道直接丢弃，带拉伸的尾巴和披风动作全部失效；关键帧间隔固定成一百毫秒，快速攀爬的中间姿势被抹平；增量编码依赖上一帧，关键帧间隔过长时误差滚雪球，落地姿势整体偏掉；同一片段被两个编码 worker 重复处理，输出帧数和字节数每次不一样；解码端把 NaN 和超出范围的值照单全收，骨骼矩阵直接失效；压缩后的片段时长和源片段对不上，循环播放时接缝跳一下；编码一批两百个片段超过预算，打包窗口卡住。bone_quant_pack.py 的 BoneQuantPack 要同时管 encode、decode 与 stats：四元数先规范符号再做最小三分量，分量索引和重建误差都要可验证；每根骨骼带自己的平移范围和缩放位宽；关键帧和增量帧分开处理，关键帧间隔可配置并保证误差有界；同一片段重复编码结果必须一致；非有限值、负范围和索引越界都要报错；一批两百个片段要在预算内完成。这十五条用例目前全是红的。

## 运行方式
```bash
python -m pytest tests -q
```
