# GSB Bugfix Task
## 题面
一家做企业协作的 SaaS 把登录入口改成输入邮箱自动跳到客户自己的 IdP，最近连续有三家客户说员工被送进了别家公司的登录页。查下来是同一个域名被两家租户声明，后注册的直接覆盖了先注册的映射；域名写成大写或者末尾多一个点就被当成全新域名，绕过原来的归属校验；Unicode 域名和 punycode 形式各存一份，仿冒者用外形相近的字母抢注后也能命中；没有完成 TXT 验证的域名同样参与发现；租户已经停用，映射还留在表里，登录落到一个早就下线的 IdP；通配符 *.corp.example 把 a.b.corp.example 这种多级子域也吞掉；邮箱本地部分带加号或点号时域名提取跑偏；映射改动要等十分钟缓存过期，切换期间整家公司登不进去；多 IdP 租户按插入顺序选中，而不是按配置的优先级；邮箱里没有 @ 时接口直接抛异常。home_realm_discovery.py 的 RealmDiscoveryIndex 要先把域名规范化成小写、去尾点、IDN 转 ASCII，再按精确匹配、验证状态、租户状态和优先级逐层筛选，通配符只允许一级且必须显式开启，冲突域名返回候选而不是随便挑一个，缓存带版本号，输入非法时返回结构化错误。test_home_realm_discovery.py 的十五个用例目前全部失败，压的是重复声明、大小写、尾点、IDN 混淆、未验证域名、停用租户、通配符越级、加号邮箱、缓存切换、优先级、非法输入、空域名、多 IdP、冲突候选和快照隔离。

## 运行方式
```bash
python -m pytest tests -q
```
