# GSB Bugfix Task
## 题面
海战地图一开，远处海面出现规则的网格状重复，像贴了一张瓷砖；FFT 谱的周期和网格尺寸对不上，浪花图案每隔几十米重复一次；三层浪按各自相位叠加，波峰互相抵消，海面变得太平；法线从高度图差分出来但没乘网格间距，浪尖黑成一片；泡沫阈值写死，风浪变大后泡沫不跟着长；船体采样五个点取平均高度，遇到大浪船头直接穿进水里；LOD 网格切换时高度场没连续，接缝处裂开一条缝；平面反射和屏幕空间反射叠在一起，海面白得发光；风速参数调到零时除零，整片海变成 NaN；相机移动时海面 UV 跟着相机走，浪看着不动；物理线程和渲染线程读同一份高度缓冲，偶尔读到撕裂的波形；每帧海洋更新预算 3ms，现在要 7ms。water_surface_fft.py 的 WaterSurfaceFft 要在 update 与两个采样入口之间保持一致：谱周期和网格尺寸匹配，多层浪相位按世界坐标对齐，法线差分乘真实间距，泡沫随浪高和风速变化，浮力采样按船体包围盒多点加权，LOD 之间共享边界高度，反射只取一种来源，风速为零时退化成静水，高度缓冲双缓冲原子切换，输出波高范围和耗时。十五条用例现在跑一遍全红。

## 运行方式
```bash
python -m pytest tests -q
```
