# GSB Bugfix Task
## 题面
开放世界骑马跨区时，玩家正前方的地面突然空了一块，马直接掉进虚空；单元加载半径按固定格数算，远处的高塔在视野里凭空弹出来；加载队列没有优先级，玩家正前方的单元排在传送点后面；离开区域立刻卸载，任务正在引用的 NPC 被一起清掉，任务直接断；传送后旧区域的请求没取消，新区域的带宽被占满，加载条卡住；跨格的大建筑依赖两个单元，只加载了一半，墙悬在空中；加载完成的回调在 IO 线程里改场景树，偶发崩溃；内存预算满了就拒绝新单元，玩家脚下没有碰撞；单元边界的导航网格没接上，NPC 走到接缝处原地打转；同一单元被多个系统重复请求，磁盘读了两遍；地图边缘、负坐标和空单元没有单独处理；主线程每帧预算 2ms，现在光调度就要 6ms。world_cell_streamer.py 的 WorldCellStreamer 把 update、request、release 都塞进一个队列：按玩家位置和视野做滞回半径，队列按距离和朝向排优先级，引用计数为零才卸载，传送时取消旧请求，跨格依赖先加载整体，回调统一切回主线程，预算不够时降级远处单元但保证脚下完整，边界单元走同一套坐标映射，重复请求合并，输出加载中、驻留和取消计数。这十五条用例现在跑一遍全红。

## 运行方式
```bash
python -m pytest tests -q
```
